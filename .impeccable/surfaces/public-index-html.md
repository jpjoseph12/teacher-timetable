Scope: the whole app shell (Today, Week, Class, Classes, Settings, Login). Mode: Operate. Audience: one Harris secondary teacher, phone between bells and desktop at a desk. Task: know now/next at a glance; write per-lesson and per-class notes that save themselves. Constraints: class colours from the teacher's Word timetable are fixed; colour is never the only signal.

## Direction contract

THESIS: The timetable is the teacher's week-to-view planner with a ribbon on now. It refuses the calendar-app default of pastel blocks on a grey-white grid with a blue now line.

OWN-WORLD: Cobalt bookcloth (#2340A8) owns the shell (rail on desktop, tab bar and header on phone). Pages are white with ruled #D9DEE8 hairlines and #15182B ink. Each lesson carries its class colour as a 7px edge tab; the class code is the same condensed form at every scale (tab, cell, panel title). A red ribbon (#D7263D) marks now. Barlow Condensed for period numbers, headings and codes; Atkinson Hyperlegible for times, body and notes.

STORY: Glance, know what's on now and next, open the lesson, write; the note saves itself and turns up on the class page later.

FIRST VIEWPORT: Desktop Week: 88px cobalt rail; ruled grid with large cobalt period numbers as the row index and break/lunch as quiet ruled bands; the opened lesson owns a right panel and the rest of the week dims. Phone Today: cobalt header with the date, a ribbon-marked now card at the top of a fixed size ramp (now > next > later), today's lesson note right under it, bottom cobalt tab bar.

FORM: Week-to-view planner, position 4 of my ordered list. seed:aa151877c9caddfc. Raises kept: fixed size ramp (star atlas), one dominant region per screen (zoo map), class code one form at every scale (Emigre specimen), focus dims the rest (streaming wall), period numbers as the index (catalog sleeve). Signature move: the red ribbon dropping down today's column to the current period.
